# Deliverable format (Security Toolset) and scope.yaml keys

The format is the one the reference pair of 2026-08-18 established; both files are generated by
`scripts/build_audit.py`, so this page is for judging output and editing scope, not for building
by hand.

## CIS-5.0-Checkliste_<kunde>_<date>.xlsx — three sheets

**Übersicht**: Kunde / Organisation (domain + org id) / Scan-Datum / Scanner / Gescannte Projekte;
"Statusverteilung (93 Kontrollen)" with `COUNTIF` formulas over the checklist's status column and a
Summe; Lesehinweise (one line per status); Werkzeuggrenzen (from `scan_caveats`); Prüfweg note;
"Auszufüllen im Review"; the list of measures Mn; an example review line.

**CIS 5.0 Checkliste**: one section header row per CIS section (fill D9E2F3), then one row per
control. Columns: `CIS # | Kontrolle | Sektion | Level | Prüfart | Status (Prowler) | Befund |
Betroffene Ressourcen | Stichprobe CISO | Prüfweg (Konsole / gcloud) | Bewertung / Kommentar |
Maßnahme`. Header fill 1F3864 white bold; review columns K and L fill FFF2CC; status cell fills
MANUAL FFE699 / PASS C6EFCE / N/A D0CECE / FAIL F8CBAD / FALSE POSITIVE BDD7EE / LÜCKE FBC7C7;
autofilter, freeze panes A2, row height 108 for FAIL/LÜCKE/MANUAL.

Status taxonomy and precedence:

| Status | meaning | when |
|---|---|---|
| FALSE POSITIVE | Prowler FAIL, control demonstrably met | `scope.false_positives[cid]` — text must contain the proof command |
| FAIL | violation on existing resources | any FAIL finding maps to the control |
| PASS | no violation on existing resources | only PASS findings |
| MANUAL | Prowler has no automated check | catalog `AssessmentStatus: Manual` or no checks (22 controls) |
| LÜCKE | no result because the foundation is missing | `scope.luecke[cid]`; automatic for 2.3/2.4 without org sink and for compute-backed controls when compute was not scanned |
| N/A (KEINE RESSOURCEN) | resource type does not exist | automated, no findings, nothing above applies |

Stichprobe CISO: PFLICHT for MANUAL, empfohlen for FAIL/LÜCKE. Prüfweg: the CIS AuditProcedure with
`ORGANIZATION_ID`, `PROJECT_ID`, `DOMAIN` replaced by real values (project = first affected own
project, else the infra project). Bewertung: seeded `[satz] …` from report-compliance (verified +
witness address, DRIFTED, partial, unmet, organizational; Checkov column when present) and from
`satz require` ("Pack stellt es bereit: <pack>"). Maßnahme: `Mn` (comma list), `Wiedervorlage` for
N/A, `Review` for MANUAL controls whose measure is not active.

**Findings (FAIL)**: `CIS # | Check-ID | Severity | Projekt | Ressource | Befund | Remediation (Kurz)`
— one row per FAIL finding in own projects; fleet collapsed to one italic row per control.

## Remediation-Plan_<kunde>_CIS-5.0_<date>.docx

Title "Remediation-Plan", framework line, header table (Kunde, Organisation, Scan-Datum, Scanner,
Scope, Status), the italic "Umsetzung nur durch Kunde/Betrieb" paragraph. Then:

1. **Ausgangslage** — scope sentence, status table (Status / Anzahl / Bewertung), "Was die Zahlen
   bedeuten" bullets (logging-foundation pattern, verified controls, drifted controls, findings ≠ problems).
2. **Reihenfolge der Maßnahmen** — one bullet per phase listing Mn — title.
3. … **Mn sections** (Heading 1 "n  Mn  Title"): 4-row table (CIS-Kontrolle with levels, Status per
   control, Aufwand, Risiko); "Befund" bullets per active control with resources; the why paragraph;
   "satz require" line when a pack provides it; "Umsetzung mit satz" code; "Alternative ohne satz
   (gcloud)" code; optional Terraform; CIS-Remediation fallback when the catalogue has no code;
   "Voraussetzungen / Warnhinweise" bullets; "Nachweis: …" italic.
4. **Bekannte False Positives** (when any), **Manuelle Kontrollen — CISO-Review** (table of all
   MANUAL controls with their measure), **Wiedervorlage** (N/A controls with the pack that pre-empts
   them), **Anhang — weitere Prowler-Befunde außerhalb CIS 5.0** (own projects, counts),
   **Nachweis der Umsetzung** (the rescan commands + expected flips), **Werkzeuggrenzen dieses
   Scans**, **Offene Punkte für das Review** (measures' open points + `scope.open_points`).

Styles: Calibri 10.5, Heading 0/1/2, Table Grid 9.5 pt, code Consolas 8.5 indented, List Bullet.

## scope.yaml keys

| key | purpose |
|---|---|
| `kunde`, `kunde_lang`, `domain`, `org_id`, `infra_project`, `iac_sa` | header values; from `discover_scope.py` |
| `scan_date`, `scan_date_de` | file names and header; `scan_date_de` free text, e.g. "10.09.2026 (Erstscan)" |
| `scanner` | one line naming tool versions and the identity (read-only, impersonation) |
| `estate_repo`, `estate_file`, `audit_dir` | paths used in the satz code blocks and the Nachweis section |
| `estate_status` | one sentence for the header's Status row |
| `fleet_regex`, `fleet_label` | generated projects to aggregate; empty = no fleet |
| `luecke` | `{cid: reason}` — automated control, no result, foundation missing |
| `false_positives` | `{cid: reason with proof command}` |
| `scan_caveats` | list; copied from MANIFEST.md "Werkzeuggrenzen" and anything you learned |
| `measures.skip` | catalogue ids to drop (e.g. `bucket-lock` when the customer decided against it) |
| `measures.override` | `{id: {title|aufwand|risiko|why|satz|gcloud|prereq|nachweis|open_point}}` |
| `measures.extra` | list of full measure objects (same fields as the catalogue) |
| `check_overrides` | `{prowler_check_id: [cid,…]}` for Prowler's CIS-map gaps (2.13 by default) |
| `open_points` | extra review questions |
| `default_region`, `retention_days` | placeholders in measure texts (defaults europe-west3, 400) |

Measure catalogue (`assets/measures.yaml`): 25 measures over all 93 controls; fields `id, title,
phase (sofort|kurzfristig|nach_freigabe|laufend|review), kind (satz-apply|satz-pack|gcloud|decision|
review), controls, packs, aufwand, risiko, why, satz, gcloud, terraform, prereq, nachweis,
open_point`; `always: true` (always emitted), `fleet_only: true` (only with a fleet; controls =
whatever fails in fleet projects). Placeholders `{org_id} {domain} {kunde} {shortcode} {estate_repo}
{estate_file} {iac_sa} {infra_project} {n_own} {n_fleet} {n_projects} {fleet_label} {fleet_regex}
{projects} {resources} {log_project} {default_region} {retention} {controls_line}`; literal braces
in code are written `{{ }}`.
