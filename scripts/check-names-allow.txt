# The privacy gate's allow-lists: the values that are shaped like private data and
# are not. ONE source, read by two readers: scripts/check-names.sh, and satz itself
# (src/privacy_shapes.rs compiles this file in, and `satz review-pack` judges a pack
# with it). A value added here is allowed by both at once.
#
# One entry per line: `<list> <extended regular expression>`. The entries of a list
# are joined with `|` into one alternation, so an entry is an ERE fragment — escape
# the dots. `#` starts a comment line; blank lines are skipped.
#
# What each list is (docs/examples.md is the register these values come from):
#   dir      Google Workspace directory ids (C0…)
#   num      11–13-digit organisation, project and folder numbers
#   bill     billing account ids
#   domain   domains and e-mail domains: the IANA-reserved names, and the vendors
#            and standards bodies this project references
#   guid     GUIDs: the four example tenants and the vendor defaults every customer
#            shares (each listed with what it is in docs/examples.md)
#   guid32   the same GUIDs without dashes (a workload identity pool id)
#   project  project ids: the example customers' projects, the placeholders the docs
#            use, and anything still carrying a param or a placeholder
